### 首页 `views/home.php`

| 每道题都带标准答案、可接受答案集合与命题陷阱分析。 | 每道题均附标准答案、可接受答案集合，以及命题意图与判断依据。 | 术语统一；书面化 |

### 登录页 `views/login.php`、`assets/js/login.js`
| 改动前 | 改动后 | 理由 |

### AI 助手 `views/admin-ai.php`
| 改动前 | 改动后 | 理由 |

## 五、题目校验文案（前后端此前各说各话，现统一）

同一问题此前后端与前端说法不同（如 hintType 非法：后端「不合法」/ 前端「必须是…之一」），
现三处（`app/validate.php`、`assets/js/admin.js`、`assets/js/admin-ai.js`）统一：

| 场景 | 统一文案 |
|---|---|
| 原句无空格 | 原句必须包含至少一个「______」空格 |
| 空格数不符 | 原句中的空格数量（N）与 blanks 数量（M）不一致 |
| 序号 | 第 N 个空的 blankIndex 应为 N，实际为 X（须从 1 开始连续递增） |
| 答案为空 | 第 N 个空：answer 不能为空 |
| 答案含空串 | 第 N 个空：answer 不能包含空字符串 |
| 提示词类型无效 | 第 N 个空：hintType「X」无效，应为 … 之一 |
| 缺提示词 | 第 N 个空：hintType 为「X」时必须填写 hintWord |
| 解析为空 | 第 N 个空：trapAnalysis 不能为空 |

同时统一了标点：中文语境一律用全角冒号「：」与全角括号「（）」。

## 七、风格规范（后续新增文案请遵循）

1. **句子**：短提示用短语（不加句号）；完整说明句加句号。
2. **标点**：中文语境用全角标点；引号统一用「」；省略号用「……」。
3. **人称**：对用户用「你」，技术说明用「PHP」「前端」等中性主语。
4. **语气**：不用「点一下」「就行了」「吧」「啦」等口语；动作用动词原形
   （复制、保存、删除），不用「去 + 动词」的口语式（除非是按钮，如「去登录」）。
5. **术语**：见第二节术语表，新增文案前先对照。
6. **数字**：数值与单位之间留空格（42 个标签、6 位）；区间用半角连字符（4-20 位）。
7. **中英混排**：中文与英文/数字之间留空格（AI 助手、JSON 文件）。
